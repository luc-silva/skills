# Skills

Custom skills for development, documentation, and process automation across repositories.

## Available Skills

- **`generate-event-docs`**: Documents asynchronous events (SQS/SNS/message queues) in AsyncAPI 3.0 and generates a single self-contained HTML file to view them.
- **`generate-flow-docs`**: Documents macro-level process flows in legacy systems using a domain-based subfolder structure, generating Mermaid diagrams and linking parameters.
- **`generate-parameter-docs`**: Reverse engineers legacy codebases to produce standardized individual Markdown files for each configuration parameter.
